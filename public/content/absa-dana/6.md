Setelah memiliki Codebook v1 sebagai panduan baku, langkah selanjutnya adalah mengeksekusi proses anotasi terhadap **2.199 ulasan mentah pengguna DANA**.

Proses anotasi ini tidak dilakukan secara gegabah dalam satu kali jalan, melainkan dibagi menjadi dua tahap batch dengan kombinasi metode *AI-assisted labeling* dan peninjauan manusia (*human adjudication*), hingga akhirnya menghasilkan dataset eksperimen final.

---

## 1. Eksekusi Anotasi Dua Batch

Untuk mengelola skala data 2.199 ulasan dengan efisien tanpa mengorbankan kualitas, strategi pelabelan dibagi menjadi dua tahap utama:

```text
Alur Eksekusi Anotasi Data:
├── Batch 1 (500 Ulasan Mentah)
│   └── Metode: Stratified sampling by rating -> AI-assisted (LLM Prompting) -> 100% Human Review & Correction
│
└── Batch 2 (1.699 Ulasan Mentah)
    └── Metode: Diproses dalam 85 sub-batch (20 ulasan/batch) via LLM Codebook-Structured Prompting -> Human Verification
```

### Penjelasan Batch 1 (500 Ulasan):
Batch 1 dirancang sebagai **tahap uji coba dan kalibrasi Codebook v1**. Sebanyak 500 ulasan diambil secara proporsional berdasarkan rating bintang (1 s.d. 5).

Teks ulasan dimasukkan ke dalam model Large Language Model (LLM) yang telah diprogram dengan *prompt* berbasis Codebook v1. Hasil draf label dari LLM kemudian diperiksa, dikoreksi, dan disetujui secara manual 100% oleh *human annotator*.

### Penjelasan Batch 2 (1.699 Ulasan):
Setelah Codebook v1 teruji stabil pada Batch 1, sisa 1.699 ulasan diproses pada Batch 2. Untuk menjaga konsistensi konteks LLM, anotasi dilakukan dalam 85 *chunk* kecil (masing-masing 20 ulasan per *prompt batch*).

Seluruh pasangan aspek-sentimen yang diekstrak oleh LLM kembali melewati tahap verifikasi manual manusia untuk memastikan tidak ada kesalahan interpretasi (*hallucination* atau *misalignment*).

Dari gabungan Batch 1 dan Batch 2 ini, ter-ekstraksi sebanyak **1.223 pasangan aspek-sentimen ter-anotasi**.

## 2. Masalah Sparsity pada Kelas Netral

Awalnya, skema klasifikasi sentimen dirancang menggunakan **3 kelas sentimen**: `Positif`, `Negatif`, dan `Netral`.

Namun ketika dilakukan analisis distribusi statistik terhadap 1.223 pasangan data ter-ekstraksi, ditemukan fakta empiris yang sangat mengejutkan:

| Kelas Sentimen | Jumlah Pasangan Data | Persentase terhadap Total Dataset |
| :--- | :---: | :---: |
| **Negatif** | 1.039 pasangan | 84,95% |
| **Positif** | 166 pasangan | 13,57% |
| **Netral** | **18 pasangan** | **1,48%** |
| **Total** | **1.223 pasangan** | **100,00%** |

Lihat betapa minimnya kelas **Netral**! Hanya ada **18 sampel** dari total 1.223 data (kurang dari 1,5%).

---

## 3. Mengapa Mempertahankan Kelas Netral Sangat Berbahaya?

Mengapa keberadaan 18 sampel kelas Netral ini menjadi masalah besar dalam Machine Learning?

Mari kita hitung simulasinya jika data ini dibagi menjadi Train set (70%), Val set (15%), dan Test set (15%):

```text
Simulasi Pembagian 18 Sampel Netral:
├── Train Set (70%)  ──► ~12 sampel Netral
├── Val Set   (15%)  ──► ~3 sampel Netral
└── Test Set  (15%)  ──► ~3 sampel Netral
```

Dalam eksperimen *classification modeling*:
1. **Model Tidak Cukup Belajar (*Extreme Data Sparsity*):** Melatih model mendalam seperti IndoBERT (124 juta parameter) hanya dengan 12 contoh sampel kelas Netral adalah hal yang mustahil. Model tidak akan pernah mengenali pola semantik kelas Netral.
2. **Metrik Evaluasi Tidak Stabil (*High Variance Evaluation*):** Di Test Set yang hanya punya 3 sampel Netral, jika model salah menebak 1 sampel saja, nilai Recall kelas Netral akan jatuh dari 100% langsung ke 66.6%. Evaluasi statistik menjadi sangat acak dan tidak valid.
3. **Karakteristik Alami Ulasan Play Store:** Pengguna yang menulis ulasan di Google Play Store jarang sekali bersikap "Netral datar". Mereka biasanya menulis ulasan karena sangat puas (Positif) atau sangat kecewa/marah (Negatif).

## 4. Keputusan Ilmiah: Mengeliminasi Kelas Netral

Berdasarkan pertimbangan metodologis di atas, diambil keputusan ilmiah yang tegas:

> **18 sampel bernilai Netral dihapus dari dataset, sehingga fokus penelitian disesuaikan secara sah menjadi klasifikasi biner 2 kelas: Negatif dan Positif.**

Setelah 18 sampel Netral dieliminasi, diperoleh **Dataset Experiment v2 Final sebanyak 1.205 pasangan aspek-sentimen**.
