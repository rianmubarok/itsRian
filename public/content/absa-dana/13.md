## 2. Kalibrasi Fungsi Loss: Weighted Cross-Entropy Loss

Ingat kembali dari Seri 1 dan 6 bahwa dataset kita mengalami ketidakseimbangan kelas yang ekstrem:
* Kelas `Negatif` (0): 724 sampel pada Train set (**86,19%**)
* Kelas `Positif` (1): 116 sampel pada Train set (**13,81%**)

Jika kita menggunakan fungsi **Cross-Entropy Loss biasa** tanpa pembobotan, gradient update dari optimizer AdamW akan didominasi oleh galat (*error*) dari kelas Negatif. Akibatnya, model akan malas belajar mengenali ulasan kelas Positif.

Untuk mengatasi ini, kita menggunakan **Weighted Cross-Entropy Loss**:

$$\mathcal{L} = -\frac{1}{N} \sum_{i=1}^{N} w_{y_i} \log P(y_i \mid x_i)$$

Di mana bobot kelas $w_k$ dihitung rasional berbalik nilai dengan frekuensi sampelnya pada Training Set (840 sampel):

$$w_k = \frac{N_{\text{train}}}{n_{\text{classes}} \times n_k}$$

Mari kita hitung bobot spesifiknya:

$$w_{\text{Negatif}} = \frac{840}{2 \times 724} = \mathbf{0.5801}$$

$$w_{\text{Positif}} = \frac{840}{2 \times 116} = \mathbf{3.6207}$$

### Makna Fisik Bobot $3.6207$:
Bobot $3.6207$ pada kelas `Positif` memberikan dorongan sanksi penalty yang **6,24 kali lebih berat** kepada optimizer AdamW ketika model salah mengklasifikasikan sampel ulasan bernilai Positif! Ini memaksa IndoBERT memberikan perhatian ekstra tinggi pada fitur-fitur pujian pengguna.

## 3. Konfigurasi Hyperparameter Fine-Tuning Final

Tabel berikut menunjukkan rincian seluruh hyperparameter fine-tuning yang digunakan secara resmi dalam eksperimen skripsi kita:

| Hyperparameter | Nilai Konfigurasi | Rationale / Alasan Ilmiah |
| :--- | :--- | :--- |
| **Max Sequence Length** | 128 Token | Mencakup 99,8% distribusi panjang ulasan Play Store tanpa membuang VRAM. |
| **Batch Size** | 16 | Ukuran batch optimal yang stabil untuk GPU Tesla T4 VRAM 16GB. |
| **Learning Rate ($\eta$)** | $2 \times 10^{-5}$ | Angka baku rekomendasi fine-tuning BERT (Devlin et al., 2019) untuk mencegah *catastrophic forgetting*. |
| **Optimizer** | AdamW ($\beta_1=0.9, \beta_2=0.999$) | Adaptive Moment Estimation dengan penanganan *Weight Decay* yang terisolasi. |
| **Weight Decay** | 0.01 | Parameter L2 regularization untuk meredam overfitting bobot parameter. |
| **Warmup Ratio** | 0.1 (10% total steps) | Menaikkan learning rate secara perlahan di 10% step awal agar gradien awal stabil. |
| **Epochs** | 5 Epoch | Jumlah iterasi yang cukup hingga loss konvergen pada validation set. |

Selama proses pelatihan berlangsung selama 5 epoch, perubahan nilai Training Loss, Validation Loss, dan Validation Macro F1 dicatat secara presisi per epoch:

Epoch 4/5 [Step 212/265]

### Analisis Kurva Pelatihan:
1. **Konvergensi Cepat:** Nilai Train Loss turun secara mulus dari 0.5412 pada Epoch 1 hingga mencapai 0.0521 pada Epoch 5.
2. **Bebas Overfitting Signifikan:** Nilai Validation Loss mencapai titik terendah pada Epoch 4 (0.1798) dan stabil di Epoch 5 (0.1824), sementara Validation Macro F1 mencapai puncaknya di angka **0.9449**.
3. **Penyimpanan Checkpoint Terbaik:** Model bobot pada Epoch 4/5 disimpan sebagai checkpoint resmi (`best_model_indobert.pt`) untuk diuji pada Test Set final.
